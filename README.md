# TalentMap AI - Universal Multi-Industry Platform

An intelligent resume analysis and job matching platform that automates candidate screening across **ALL INDUSTRIES** - from Technology and Healthcare to Finance, Legal, Engineering, and beyond.

## Purpose

TalentMap AI analyzes resumes and matches them against job requirements using advanced skill detection covering **20+ industries** with **500+ skills**. It provides instant, objective candidate assessments across Technology, Healthcare, Finance, Engineering, Legal, Marketing, Education, and many more industries.

## Key Features

- **Smart Resume Processing**: Supports TXT and DOCX formats with automatic text extraction
- **Multi-Industry Skill Detection**: Identifies 500+ technical and professional skills across 20+ industries
- **Universal Experience Analysis**: Evaluates years of experience and seniority levels across all fields
- **Intelligent Cross-Industry Matching**: Provides detailed match scores for any industry or role
- **Comprehensive Data Extraction**: Automatically extracts contact info, education, and work experience

## How It Works

1. **Upload Resume**: Submit TXT or DOCX resume files
2. **Define Job Requirements**: Input required skills and experience level
3. **AI Analysis**: System extracts skills, experience, and contact information
4. **Match Scoring**: Generates compatibility score with detailed feedback
5. **Decision Support**: Provides hiring recommendations based on analysis

## Technology Stack

- **Frontend**: React + TypeScript + Tailwind CSS
- **Processing**: Advanced text analysis and pattern recognition
- **File Support**: TXT (recommended) and DOCX formats
- **Deployment**: Vite build system for optimal performance

## 🛠️ Installation

1. **Clone the repository:**
   ```sh
   git clone https://github.com/shyakachaste/talentmapai.git
   cd talentmapai
   ```
2. **Install dependencies:**
   ```sh
   npm install
   ```
3. **Start the development server:**
   ```sh
   npm run dev
   ```
   The app will be available at [http://localhost:8080](http://localhost:8080)

4. **Build for production:**
   ```sh
   npm run build
   ```
   The production build will be in the `dist/` folder.

## 🧑‍💻 Requirements
- Node.js (v18 or newer recommended)
- npm (v9 or newer recommended)
- Windows, Mac, or Linux
